# 24-bit PCM5102A Stereo DAC Digital-to-analog Converter PLL Voice Module pHAT
PCM5102A-ESP32-Internet-Radio — це проект мережевого інтернет-радіоприймача на базі мікроконтролера ESP32 та високоякісного ЦАП (DAC) модуля PCM5102A.

Проект призначений для потокового відтворення аудіостанцій (AAC / MP3) через Wi-Fi з високою якістю звуку за інтерфейсом I2S.

✨ Основні можливості:
Висока якість звуку: Використання зовнішнього Hi-Fi ЦАП PCM5102A (24-bit / 192kHz) замість стандартних аналогових виходів ESP32.

Підтримка I2S протоколу: Цифрова передача аудіосигналу з мінімальними затримками та спотвореннями.

Потокове відтворення: Стабільне декодування онлайн-радіостанцій через Wi-Fi.

Просте налаштування: Зручне підключення та можливість гнучкої конфігурації списку радіостанцій і мережевих параметрів.

## Розпіновка DAC модуля

- VCC 5V
- GND GND
- SCK - GND
- BCK 4 
- DIN 6 
- LRCK  5 

Інший бік - 
- FMT GND
- XSMT 3.3V
- DEMP - GND


## Розпіновка дисплея

- SDA 1 
- SCL 2 

## Розпіновка енкодера

- S1 41
- S2 42 
- KEY 40

## Розпіновка ІЧ-приймача LF0038M

(відлік ніжок від скошеного краю лінзи)
- 1 - 18
- 2 - GND
- 3 - VCC +5V

## Склад системи

- ESP32 S3 N16R8 - контролер
- PAM-8403 - підсилювач
- PCM5102A - ЦАП (цифро-аналоговий перетворювач)
- EC11 - енкодер
- ІЧ-приймач LF0038M
